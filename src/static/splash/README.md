# 启动页图片配置说明

## 图片尺寸要求

### Android 启动页图片

请将以下尺寸的启动页图片放置到 `android` 目录下：

- **hdpi.png**: 480x800 像素（中等密度屏幕）
- **xhdpi.png**: 720x1280 像素（高密度屏幕）
- **xxhdpi.png**: 1080x1920 像素（超高密度屏幕）
- **xxxhdpi.png**: 1440x2560 像素（超超高密度屏幕）

### iOS 启动页图片

请将以下尺寸的启动页图片放置到 `ios` 目录下：

#### iPhone
- **iphone@2x.png**: 750x1334 像素（iPhone 6/7/8）
- **iphone@3x.png**: 1242x2208 像素（iPhone 6 Plus/7 Plus/8 Plus 及以上）

#### iPad
- **ipad.png**: 768x1024 像素（iPad 1x）
- **ipad@2x.png**: 1536x2048 像素（iPad 2x）

## 图片要求

1. **格式**: PNG 格式（支持透明背景）
2. **内容**: 建议使用应用 Logo 或品牌标识
3. **背景**: 可以使用纯色背景或渐变背景
4. **尺寸**: 严格按照上述尺寸制作，避免拉伸变形

## 使用说明

1. 将制作好的启动页图片按照上述命名规则放入对应目录
2. 在 HBuilderX 中重新编译打包应用
3. 启动页图片会在应用启动时自动显示

## 注意事项

- 启动页图片会在应用启动时显示，直到应用首页加载完成
- 可以通过 `manifest.json` 中的 `splashscreen.delay` 配置延迟关闭时间
- 建议启动页图片与应用的品牌风格保持一致
